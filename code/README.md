## Code Availability

The analysis code associated with our manuscript, "A Causally Guided Imaging-Informatics Framework for Ranking DXA-Derived Hip Imaging Phenotypes in Hip Fracture Risk Prediction," accepted by the Journal of Imaging Informatics in Medicine, is publicly available in this repository.

### Code Organization

The code is organized into three components:

- **dowhy/**: Backdoor causal effect estimation, refutation analyses, and subgroup analyses.
- **causalforestdml/**: CausalForestDML estimation, treatment effect heterogeneity analysis, and visualization.
- **predictive_modeling/**: Machine learning model comparisons, logistic regression analyses, and causal feature-based prediction.

### Data Availability

Patient-level data are not publicly available due to data use restrictions and participant confidentiality requirements. Researchers with authorized access to the corresponding data may use these scripts to reproduce the analyses.

For installation instructions and usage examples, please refer to the main README.md in the repository root.
